# Design baseline

The application is an empty canvas. It has no visible product interface, typography scale, layout, or component styling yet.

The shadcn theme setup remains available in `src/react-app/index.css`: semantic light and dark color tokens, radius values, Tailwind mappings, and the Geist Variable font import. These are implementation defaults, not an approved visual direction for the polling experience.

## Canvas boundary

- Keep the app root free of demo content and starter layout styles.
- Use semantic theme tokens when product UI is designed.
- Choose product typography, layout, components, and any brand assets as part of future interface work.
